Apply a unified diff patch to one or more files (shell form).

Script structure: same as other shell-mode tools.

# apply a patch:
    apply_patch <<PATCH
    --- a/file.ts
    +++ b/file.ts
    @@ -1,3 +1,4 @@
     const x = 1
    +const y = 2
     console.log(x)
    PATCH

The patch format is standard unified diff (as produced by `diff -u`).
Multi-hunk and multi-file patches are supported.

Example:
    apply_patch <<PATCH
    --- a/src/index.ts
    +++ b/src/index.ts
    @@ -5,7 +5,7 @@
     function hello() {
    -  return "hi"
    +  return "hello"
     }
    PATCH
